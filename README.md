# ShareNot-Fast
**ShareNot Fast**

A community-modified build of ShareNot focused on responsive screen capture, customizable hotkeys, and local-first screenshot workflows.

**Why this build?**

This project is intended for users who want a responsive screenshot utility with the flexibility of ShareNot, without unnecessary features for their daily workflow.

**Highlights**

 **- Responsive screen capture:** Removes selected components, including the Modern Image Editor, to streamline the workflow.

 **- Customizable screenshot hotkeys:** Adds an override for the Windows Win + Shift + S screenshot shortcut.

 **- Local-first workflow:** Preserves the project's no-automatic-upload approach for users who prefer to keep screenshots local.

 **- Free and open source:** Source code is available for inspection and modification under the applicable license.

**Security and privacy**

This project is designed to support local screenshot workflows. Users should review the source code and their own configuration before deploying it in a corporate environment.

A clean antivirus scan is not a guarantee that software is completely free of security vulnerabilities.
